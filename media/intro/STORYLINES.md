# context-flow 紹介動画 ― 3 本の筋

採用は A。1 つの長いセッション(orders-api:注文 API にバリデーションを足す、12 ターン済み)に途中からペインを足し、13 ターン目を送ってから要約が届くまでを追う。軸は「長いセッションでも、話の流れを見失わない」。

## A. 流れを取り戻す(採用)
- 装置:Life before / after + 機能そのものがフック。形:1 枚の枠が組み替わる(端末の窓は動かず、中身だけ変わる。claude-cockpit の動画と同じ枠)
- 最初の 2 秒:Claude Code の transcript が 1 枚。4 ターンぶんが流れていき、どこまで何が決まったかは読めない
- 拍:hook(見失う)→ reveal(窓が割れて右に 1 枚。起動アニメーション。途中からでも流れが起き、細かいターンが節にまとまる)→ 流れ(本筋と寄り道)→ 決まったこと・残っていること → いま(送信・ツール・サブエージェント)→ 固定 / スクロール → 要約の打ち出しと節の区切り直し → 節・枝で飛ぶ → 背景の配色 → end(インストール 1 行)
- 見た目:地 #e9e6df、catppuccin mocha の端末、JetBrains Mono。色はペイン自身の虹だけ
- 音:Kokoro jf_alpha の日本語ナレーション、Drift – Minimal(CC BY)を −20 dB で下に、key / whoosh

## B. 年表そのもの
- 装置:物が説明(1 本の縦の線が画面の中央に伸び、節と枝が 1 つずつ点く)。形:連続 1 カット
- 却下:本物の画面(左に Claude Code、右にペイン)が出てこない。「横に出る」という置き場所が伝わらない

## C. 3 時間後
